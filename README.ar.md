نور تطبيق إسلامي يومي للقراءة والاستماع والمحافظة على الورد: المصحف كاملاً مع
التفسير، والكتب التسعة مع أدوات دراسة الإسناد، ومواقيت الصلاة مع الأذان،
والقبلة، والأذكار مع مصادرها.

كل ما يحتاجه المسلم يومياً يعمل **دون إنترنت إطلاقاً** — القرآن والحديث
والتفسير والأذكار مضمّنة داخل التطبيق. لا حساب تُنشئه، ولا إعلانات تُعرض
عليك، ولا بيانات شخصية تخرج من جهازك إلا إذا فعّلت أنت عدّادات الاستخدام
(مجمّعة فقط) بنفسك.

## الأرقام

كل رقم أدناه قابل للتحقق داخل هذا المستودع، وأغلبه محروس بوابات تكامل مستمر
حتى لا ينحرف بصمت.

| | القيمة | الحارس |
|---|---|---|
| الاختبارات | ٦٥١ اختباراً، كلها خضراء | `flutter test` |
| تغطية الأسطر | ٣٠٫٧٠٪ (الحد الأدنى ٣٠) | `tools/coverage_summary.py` |
| كتب الحديث | ٩ كتب رئيسية + الأربعون النووية | `assets/db/hadith.db` (ببصمة تحقق) |
| مصادر التفسير | ٤ — الميسر، ابن كثير، السعدي، الطبري | `assets/db/` (ببصمة تحقق) |
| المصحف | ٦٠٤ صفحات بنص عثماني | بصمة تحقق + اختبار سلامة |
| طرق حساب المواقيت | ١٩ طريقة مع إعدادات إقليمية | `prayer_time_models.dart` |
| حجم الحزمة | ٢٢١٫٨ ميجابايت (السقف ٢٣٠) | `tools/check_assets_size.py` |
| تطابق النصوص عربي/إنجليزي | ٦٦٢ مفتاحاً لكل لغة | `tools/check_arb_parity.py` |
| التحليل الساكن | صفر ملاحظات | `flutter analyze` |
| سقف حجم الملفات | مفروض، مع ١٣ ملفاً موروثاً مسجّلاً ومحدوداً في خط الأساس | `tools/file_size_check.py` |

## ما الذي يقدّمه

**القرآن** — المصحف كاملاً (٦٠٤ صفحات) بنص عثماني، وخطة ختمة تحوّل «اقرأ
القرآن كاملاً» إلى ورد يومي متتابع، وتلاوة بالتشغيل في الخلفية، وأربعة مصادر
تفسير كلاسيكية مربوطة بالآية التي تقرأها، وملاحظات ومحفوظات على مستوى الآية،
وبطاقات آيات قابلة للتصدير كصور.

**الحديث** — الكتب التسعة والأربعون النووية، مع بحث نصّي كامل يطبّع العربية
(التشكيل وصور الهمزات والتاء المربوطة)، فـ«الرحمن» يجد «ٱلرحمن». ويضيف وضع
طالب العلم عرض سلسلة الإسناد، والبحث عن الرواة، ومقارنة الروايات بين الكتب،
وشجرة الموضوعات، ونظام حفظ بالتكرار المتباعد (FSRS) مع اختبارات وإحصاءات.

**الصلاة والقبلة** — ١٩ طريقة حسابية مع إعدادات لكل بلد، وتصحيح فصلي، وجدولة
الأذان، ومتابعة الصلوات الفائتة، و«وضع المسجد» الذي يهدئ الواجهة عند
الجماعة، وبوصلة قبلة تُحسب بالدائرة العظمى.

**الأذكار والأدوات** — أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ مع
عدّادات ومراجع، ومسبحة رقمية، واقتراحات حسب وقت اليوم.

**الورد اليومي** — آلة حالة يومية تتبّع موضعك في يومك (الفجر ← الأذكار ← الظهر
← …)، وتعرض التالي في وقته، وتحفظ السلاسل والإحصاءات، وتعرض المواقيت على
الودجة الرئيسية للجهاز.

**اللغات والوصول** — العربية والإنجليزية بتطابق مفاتيح محروس، واتجاه صحيح
RTL/LTR، ووسوم قارئ الشاشة على المسارات الرئيسية مع أحجام لمس متحقَّق منها عبر
إرشادات الوصول في Flutter (`docs/accessibility.md`).

## الخصوصية بالتصميم

- **بلا حساب، بلا إعلانات، بلا أي حزمة تحليلات طرف ثالث.** التطبيق يقدّم
  عدّادات اختيارية من صنعه، مغلقة افتراضياً: قائمة أحداث محدودة
  (`app_open`، `surah_opened`، …) وعدّادات مجمّعة فقط — بلا هوية ولا أوقات ولا
  محتوى — ولا شيء يغادر الجهاز إلا إذا هيّأت أنت نقطة استقبال.
- **تقارير الأعطال اختيارية وبلا بيانات هوية**، فقط عند تمرير DSN وقت البناء،
  مع `sendDefaultPii: false` و`attachScreenshot: false` وإيقاف التتبّع.
- **الموقع يبقى على الجهاز** — يُستخدم لحساب المواقيت والقبلة، ولا يُرسل أبداً.
- **ملاحظاتك مشفّرة** على الجهاز، والمحفوظات والتقدّم والإحصاءات في تخزين محلي
  فقط.

## سلامة المحتوى

المحتوى الديني يستحق نفس الصرامة التي يستحقها الكود:

- **بصمات تحقق لكل مجموعة محتوى** (القرآن، الحديث، الأذكار، الرواة) عبر ملفات
  `.sha256` جانبية، فيُكشف أي تغيير صامت.
- **سجل مراجعة علمية** (`docs/scholarly-review.md`) يربط كل مجموعة محتوى ببصمة
  تجميدها وحالة مراجعتها. المراجعة تمنع الإصدار.
- **قاعدة الرواة لا تختلق.** حقول أحكام *علم الرجال* موجودة في المخطط لكنها
  تُملأ فقط عند وجود مصدر — الحقل الفارغ أمانة، والحكم المُختلق ليس كذلك.
- **حرّاس ضد انحراف التوثيق**: اختبار حارس ادعاءات يُفشل البناء إذا أعلن
  مستند موجّه للمستخدم عن قدرة غير موجودة في الكود، وحارس ترميز يُفشل البناء
  عند أي نص عربي تالف.

## التثبيت

```bash
git clone https://github.com/DukePan/noor-app.git
cd noor-app
flutter pub get
flutter run                 # جهاز أو محاكي أندرويد/آي أو إس متصل
```

يحتاج قناة Flutter المستقرة (Dart ≥ 3.0). المزايا الأساسية لا تحتاج إنترنت؛
وعند أول تشغيل تُستورد قاعدة بيانات الحديث المضمّنة مرة واحدة.

> **الويب غير مدعوم.** يعتمد التطبيق على إضافات أصلية (SQLite، وجدولة الأذان،
> وتشغيل الصوت في الخلفية، والبوصلة، وتحديد الموقع) لا تنفيذ لها على الويب.

تقارير الأعطال اختيارية، ووقت البناء فقط:

```bash
flutter run --dart-define=SENTRY_DSN=https://your-dsn@sentry.io/project
```

أو ابنِ نسخ الإصدار:

```bash
flutter build appbundle --release   # جوجل بلاي
flutter build ipa --release         # آب ستور
```

## الأسئلة الشائعة

**لماذا حجم التنزيل ٢٢١ ميجابايت؟**
لأن القرآن وأربعة مصادر تفسير والكتب التسعة تأتي داخل التطبيق حتى لا يحتاج
شيء إلى اتصال — في وضع الطيران أو في قبو مسجد. الحجم محروس بسقف ٢٣٠
ميجابايت، ونقل قواعد البيانات المرجعية إلى حزم عند الطلب قرار مؤجّل بعد
الإصدار الأول ومسجّل في `docs/store-checklist.md`.

**هل يعمل حقاً دون إنترنت؟**
نعم لكل المحتوى الأساسي. الشبكة تُستخدم فقط لجلب اختياري (التفسير المضمّن
يغطي المصادر الأربعة، والتلاوة تُبثّ إن اخترت قارئاً عن بُعد).

**ماذا تجمعون عني؟**
لا شيء افتراضياً. تقارير الأعطال وعدّادات الاستخدام اختيارية، والعدّادات
مجمّعة فقط بلا هوية ولا أوقات ولا محتوى، ولا تُشارك مع أي طرف ثالث.

**لماذا بعض حقول توثيق الرواة فارغة؟**
لأن ملأها يحتاج مصدراً. التطبيق يفضّل حقلاً فارغاً على حكم مُختلق في علم
الرجال — انظر `docs/scholarly-review.md`.

**هل المصدر مفتوح؟**
لا. المستودع ملكي (انظر [LICENSE](LICENSE))، والتطبيق المنشور مجاني
للاستخدام.

**كيف أُعيد توليد العرض المتحرك أو أحصل على صور الشاشة؟**
في `docs/media/README.md` تجد أوامر التوليد ومواصفات استبداله بتسجيل حقيقي من
جهاز.
