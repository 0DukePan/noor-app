# Font Assets
This directory contains Arabic fonts for the app.

## Required Fonts
1. **AmiriQuran-Regular.ttf** - For Quran text display
2. **Cairo-Regular.ttf** - For UI text
3. **Cairo-Bold.ttf** - For headings

## Font Sources
- Amiri Quran: https://github.com/aliftype/amiri
- Cairo: https://fonts.google.com/specimen/Cairo
